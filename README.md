# Social Username Checker

API REST para verificar usernames em redes sociais usando Python e FastAPI.

## Redes sociais

- Instagram
- Facebook
- X
- TikTok
- Threads

## Tecnologias

- Python
- FastAPI
- HTTPX
- Pydantic
- Asyncio
